# Ngasir — Aplikasi Kasir dan Stok Produk

Aplikasi web sederhana untuk membantu toko mencatat produk, kategori, stok, dan transaksi penjualan.

## Latar Belakang
Pencatatan manual dapat menyulitkan pengelolaan produk dan rekap transaksi. KasirKu direncanakan untuk menyatukan informasi tersebut dalam satu aplikasi web.

## Manfaat Aplikasi
Aplikasi Ngasir membantu pengguna mengelola data produk, kategori, dan stok barang secara lebih terorganisir. Aplikasi ini juga mempermudah pencatatan transaksi, perhitungan total penjualan, serta pemantauan informasi melalui dashboard.

## Target Pengguna
- Admin/kasir sebagai pengguna utama untuk melakukan transaksi dan pencatatan produk.
- Pemilik toko sebagai pengguna opsional untuk melihat ringkasan penjualan.

## Fitur Rencana
- Login untuk masuk ke sesi admin, kasir, maupun owner dan logout untuk keluar dari sesi.
- Dashboard ringkasan yang berisi tentang ringkasan jumlah produk, transaksi, dan penjualan.
- Pengelolaan produk dan kategori untuk melihat, menambah, dan menghapus data produk.
- Tampilan stok produk untuk melihat ketersediaan produk.
- Pencatatan transaksi dan detail transaksi mencatat transaksi penjualan, memilih produk yang dibeli, menentukan jumlah barang, dan menghitung total pembayaran.
- Pencarian/filter daftar data untuk memudahkan pengguna mencari produk, kategori, atau data transaksi berdasarkan kata kunci maupun kriteria tertentu.
